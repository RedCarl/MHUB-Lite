能做什么What it does

插上设备就能用，改完就能走。Plug in, tune it, walk away.

鼠标Mouse

电量、充电状态、连接方式一眼看全；1–6 档 DPI 随手切，回报率、按键防抖、无线休眠都能调。支持 G3 V2 与 A7 V3 Ultra+。Battery, charging state and connection at a glance. Switch between 1–6 DPI stages and tune polling rate, debounce and wireless sleep. Supports G3 V2 and A7 V3 Ultra+.

三层改键Three-layer remap

Default / Fn / Fn2 三层，99 键可视化布局。任意键可映射成其他按键、修饰键、媒体键或自定义代码；K99 V2 2.4G 已支持。Default / Fn / Fn2 layers over a 99-key visual layout. Map any key to another key, a modifier, a media key or a custom code. K99 V2 2.4G is supported.

灯效Lighting

模式、亮度、速度、单色 / 多彩都能调；鼠标和键盘各管各的，改完写进设备，换台电脑也还是这套。Tune mode, brightness, speed and single/multi-colour lighting. Mouse and keyboard keep their own settings, stored on the device itself.

即时保存Instant save

没有「草稿 → 应用」两步。改完一两秒自动写入，侧边栏显示「保存中… / 已保存」；连续拖动滑块会合并成一次写入。No draft-then-apply dance. Changes commit a second or two after you stop, the sidebar shows "Saving… / Saved", and rapid slider drags collapse into one write.

多设备Multiple devices

鼠标和键盘可以同时连接，侧边栏顶部切换当前设备，导航跟着变；设置固定在底部，不占导航的位置。Mouse and keyboard can be connected at once. Switch device from the top of the sidebar and the nav follows; settings stay pinned to the bottom.

后台与低电量提醒Tray and low-battery alerts

关窗口只是收进托盘 / 菜单栏，电量继续监测；macOS 点菜单栏图标就能看鼠标和键盘的百分比，也能直接打开客户端或退出。低于 20% 通知一次，充电不打扰。Closing the window tucks it into the tray or menu bar and monitoring keeps running. On macOS the menu bar icon shows mouse and keyboard percentages and can open the client or quit. One alert below 20%, silence while charging.
